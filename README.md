# Make the Judge Smile

A single warm, surprising line about a small good thing that happened
today — a neighbour's cat, two years of indifference, and one 5:40 a.m.
headbutt. `main.py` writes the line to `/output/entry.txt` (or to
`$OUTPUT_PATH` when set). Deterministic, stdlib only, no network.
